# Thiru-Food-Web
🍴 Thiru FoodWeb – FoodMunch

FoodMunch is a beautifully designed and responsive restaurant website built under the project name Thiru FoodWeb. It offers an elegant digital dining experience, showcasing delicious dishes, mouth-watering visuals, and smooth navigation — all crafted to reflect a modern food brand identity.

✨ Key Features

🍽️ Home Page: Captures visitors with a warm welcome, featured dishes, and inviting visuals.

📜 Menu Section: Displays a wide range of food items with clear presentation and appealing design.

🧾 About Section: Highlights the restaurant’s story, values, and passion for great food.

📞 Contact Section: Simple form and details for easy reservations or inquiries.

💻 Fully Responsive: Optimized for all screen sizes — mobile, tablet, and desktop.

💻 Technologies Used

HTML5 – For structure and semantic layout

CSS3 – For styling, colors, and responsive design

Bootstrap – For grid system and mobile-friendly components

🎯 Project Purpose

This project showcases front-end development skills, combining design, usability, and responsiveness. It serves as a perfect example of how simple web technologies can create a professional restaurant website that engages users and builds brand trust.
